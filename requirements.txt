# eTrak server runtime dependencies.
#
# Install with:  pip install -r requirements.txt
#
# Every version is pinned because this has to run unattended on a client
# machine. Two constraints worth knowing:
#
#   * numpy must stay < 2. onnxruntime 1.19 and this stack are built against
#     the 1.x ABI; numpy 2 breaks the native extension at import time.
#   * onnxruntime is the inference engine, NOT tensorflow and NOT tflite.
#     tflite-runtime publishes no Windows wheel; the model is therefore shipped
#     as .onnx, verified numerically identical to the original .tflite.
